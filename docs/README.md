# NeuralCanvas Visual Assets & Demo Recordings

This directory stores visual assets and recording instructions for NeuralCanvas.

## Hero Demo Recording Guidelines

To record the official project demo:
1. Open [http://localhost:3000](http://localhost:3000).
2. Set viewport to ~1000px wide.
3. Click a preset (e.g., `Setosa`).
4. Click **Run inference**.
5. Capture pulse propagation, 3D neuron activation, output resolution, and ripple effect.
6. Export as high-quality GIF or MP4 (< 6 seconds loop, < 10 MB).
